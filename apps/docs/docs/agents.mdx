## JSON output

Pass `--format json` for one object on stdout. Errors arrive as one object on stderr.

```sh
motif "amber bottles and a brass dish on a walnut shelf" --format json
```

## Price a run first

`--dry-run` reports the cost before anything is spent. A cost of null means the total is unknown, not free.

```sh
motif erase "the parked car" street.jpg --dry-run --fields cost,costBasis,output
```

## Sizes

Resolution names (`1K`, `2K`, `4K`) are tiers, not exact pixels, and what they mean depends on the Model. `--dry-run` reports `size` (`{ width, height }`) when Motif asks for an exact size and `null` when the Model decides; `motif --describe generate` lists each Model's `sizing`.

## Image format

Images come back as PNG unless you ask for another format with `--output-format jpeg|webp` or an `-o` ending `.jpg` or `.webp`. Convert afterwards for anything else.

## Errors and exit codes

The exit code and the error object always agree, so branch on the code.

| Exit | Meaning                | Error codes          |
| ---- | ---------------------- | -------------------- |
| 0    | Success                |                      |
| 2    | Invalid input or usage | `INVALID_OPTION`     |
| 2    | No Model can do it     | `NO_MODEL_AVAILABLE` |
| 3    | Key missing or refused | `MISSING_API_KEY`    |
| 4    | Not found              | `NO_PREVIOUS`        |
| 5    | The provider failed    | `TASK_FAILED`        |

## Read the schema

Read one command's schema before you call it.

```sh
motif --describe erase --format json
```
